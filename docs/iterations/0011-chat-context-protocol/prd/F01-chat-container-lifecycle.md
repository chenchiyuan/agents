# F01：chat 容器与生命周期

**功能 ID**: F01
**来源**: `demand.md` C-1（chat 是闭环容器）；关联 D-3（持久化形态，落到 F02/F07）
**迭代**: 0011-chat-context-protocol

---

## 用户价值

一次 chat 处理一件闭环且独立的事情——用户有明确的容器边界来组织对话，并在列表中一眼看出每个对话的主题、进度与时间。

## 验收标准

1. **新建即入列**：用户在不指定既有 chat 的情况下提交第一条输入 → 系统创建新 chat，该 chat 立即出现在 chat 列表中，条目含标题、状态、创建时间（C-1）。
2. **标题非空**：每个 chat 有非空标题；新建时未提供标题 → 以该 chat 首条输入文本生成标题（生成时机 = 首条输入落盘的同一步骤；截断长度上限 = 40 字符——见「架构维度」）`[model_inferred]`。
3. **状态可观察**：chat 状态至少可区分四种用户可观察情形——B 正在处理时为「处理中」；输出已产生后为「已完成」；B 处理失败时为「失败」；用户关闭后为「已关闭」（C-1）。状态取值集合与命名：`working`（处理中）/ `completed`（已完成）/ `failed`（失败）/ `closed`（已关闭）——见「架构维度」`[model_inferred]`。
4. **时间戳**：每个 chat 记录创建时间与更新时间；该 chat 新增输入或输出后，更新时间随之前移（C-1）。
5. **可关闭**：用户可关闭一个 chat；关闭后该 chat 状态为「已关闭」，不再接受新的输入（提交被明确拒绝并给出提示），历史内容仍可读（C-1；只读读取能力见 F03-8）`[model_inferred]`。
6. **关闭不删数据**：关闭只改变状态与可写性，不删除该 chat 的输入/输出记录——关闭后仍可在列表中找到并打开读取（C-1/C-3）。

## 边界（不包含）

- 不做删除 / 归档 / 导出 chat——本迭代只提供「创建 + 关闭 + 查询」（C-1 只要求"可关闭"）。
- 不做 chat 重命名（demand 未要求；标题来源见验收 2）。
- 不做关闭后的恢复 / 重开语义（本迭代不提供重开：已关闭 chat 拒绝新输入，故不存在"重开后的上下文来源"；见「架构维度」AR-03）。
- 不做多用户共享、可见性与权限隔离（N-4）。
- 不做 chat 模板 / 分组 / 标签（demand 外）。
- chat 容器内的上下文行为不在本卡（见 F05）。

## 架构维度（阶段 3 已填，2026-09-10；详见 `architecture.md` §4.1/§4.3/§6.4）

- **chat 标识与状态承载**：`chat_id = 'chat-' + crypto.randomUUID()`，落 `chats.chat_id`（SQLite 主键）。状态取值 `working | completed | failed | closed`（**无 idle**——chat 的创建与首条输入同步发生，idle 不可观察），承载于 `chats.state`；流转：创建即 `working` → `completed` / `failed`（该轮输出落盘时），任意态 → `closed`（用户关闭）；`closed` 为终态，状态写入带 `WHERE state!='closed'` 哨兵，迟到结果不覆盖（对应验收 3）。
- **标题时机与上限**：在 `POST /api/messages` 内、首条输入落盘的**同一步骤**生成；`title = text.trim().slice(0, 40)`（40 字符上限沿用 0010 `registry.createChat` 既有值）；后续输入不改标题，不提供重命名（对应验收 2）。
- **时间戳精度与更新触发点**：毫秒 epoch（`Date.now()`）；`updated_at` 在「新增输入」「新增输出」「关闭」三处前移，`closed_at` 记录关闭时刻（对应验收 4）。
- **关闭与上下文**：关闭 = **立即释放上下文**（web 向该 chat 出现过的各 agent 发 `notice{kind:'context_release', chat_id}` → agent kill 该 chat 的常驻进程并移除键），同时置 `state='closed'`；**已关闭 chat 不允许再次提问**（`POST /api/messages` → 409 + 提示），因此不存在"重开后上下文来源"这一分支；关闭不删数据（对应验收 5/6，与 F05 架构维度呼应）。
