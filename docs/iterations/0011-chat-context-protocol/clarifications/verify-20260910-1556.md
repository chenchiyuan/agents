## 下一迭代候选

- **投递失败的静默性**（偏差 #8 的推广）：`task.result`/`task.update` 在任何"origin 非 online"或"web 未知 task_id"路径上都是静默丢弃；建议加最小可观测面（web 侧一条 `TASK_RESULT_UNKNOWN` 日志/计数、Router 侧 `MESSAGE_NOT_DELIVERED` 事件），否则"输出消失"类故障只能靠肉眼发现。
- **注册身份冲突的可观测性**：同 `instance_id` 的替换目前只体现在 Router 内部；可考虑 `agent.replaced` 已有通知面（`NodeClient.replaced`/`onReplaced`）在 web 侧也被消费并记日志。
- **续跑 L1-6 门禁**：默认模型两条路径对照复测（§7.5 步骤 4）仍未闭环；本次实测再次出现 90 s 无响应与 30×s 级尾延迟。
- **`status.md` 生成自动化**：状态视图与 git 事实连续两轮出现漂移（§18.1 NC-15 已记同类），可考虑由脚本按 git/PR 卡生成该表，减少人工回填漏项。
- **常量与文档的单一来源**：transport 成员数、错误码表（404）等"文档抄写型"不一致（偏差 #5/#6）可通过"文档引用代码常量/测试断言"的方式消解。
- **`pickPort()` 冲突回退**（承 NC-9）：本次两次全量跑未触发，风险仍在。
