### V4 SSE 实时与事件序列（E-4）—— **pass**

- **事件序列（独立探针实得原始帧）**：
  `message(in) | chat_state(working) | task_update(chunk:VE) | task_update(chunk:RIF) | task_update(chunk:Y<VERIFY-ROUND-2>) | message(out) | chat_state(completed)`
  → 顺序满足 `message(in) < 首个 task_update`、`全部 task_update < message(out)`、状态含 working 与 completed。
- **E-4**：`task_update` 数 = 3（≥2），全部 `kind='chunk'`、文本长度递增，拼接长度 22 = `VERIFY<VERIFY-ROUND-2>`.length（22）→ "终态到达前内容已增长"成立。
- **关联正确**：每个 `task_update` 的 `chat_id` = 订阅的 chat、`task_id` = `POST` 响应中的 `task_id`（证明 MI-5 的 `task_id→chat_id` 登记表生效，而非依赖 body 里的 chat_id）。

### V5 关闭语义与 notice 归属 —— **pass**

- **关闭 → 200 `{chat_id,state:'closed'}`**，DB `state='closed'`、`closed_at/updated_at` 前移；SSE 收到 `chat_state(closed)`；**数据不删**（行数不变，详情仍返回完整消息流）；列表仍含该 chat 且 `state=closed` 过滤命中。
- **幂等**：二次 `POST /close` → 仍 200 `closed`，SSE 上 notice 数**仍为 1**（不重复提示）。
- **释放控制消息与提示归属（决定性证据）**：
  - 有注册 agent 的 chat 关闭 → SSE 恰 **1 条** `notice`，`kind='context_released'`、`chat_id` 正确、`text='对话已关闭，上下文已释放'`（该提示由 agent 回发、web 转发）。
  - **无任何已注册 agent 的 chat**（`agent_id='ghost-9'`，派发失败但 chat 已建）关闭 → SSE `events = chat_state`，**notice 数 = 0**。这条锁死"web 不自行 publish notice"：若 web 自行 publish，此场景必出 1 条。
  - 代码位：`web.js:196-203`（notice 分支只转发，入场条件 `kind ∈ {context_released, context_reset}`）、`:325-333`（close 只发控制消息 `context_release` + 推 `chat_state`；幂等早返回在 `:322-324`）。
- **已关闭 chat 提交 → 409** `{"error":"chat 已关闭，不接受新输入"}`，且 DB 行数不变（4 → 4）。
- **迟到终态哨兵（MI-7）**：慢 ACP（2s）在飞时先 close → 终态随后到达：DB `state` 仍 `closed`、out 记录仍写入（`error='context_crashed'`，符合 §6.4「在飞轮次走崩溃路径收尾」）、SSE 全程**未**出现 `chat_state(completed)`（实得 `["closed","closed"]`）、API 回读 `state=closed` 且消息 2 条。
- **未知 chat close → 404**，与详情同口径。

## 下一迭代候选

- **C1（建议修复，1 行级）**：`POST /api/messages` 收到**畸形 JSON body** 时返回 **502** 且文案误导为「router 不可达或请求失败」——实测 `curl --data '{bad json'` → `502 {"error":"router 不可达或请求失败: invalid JSON body: …"}`；成因是 `readBody` 的抛错（`web.js:61-72`）被 `web.js:417-419` 的外层 `catch` 统一归类为 502。客户端输入错误应归 400（架构 §4.5/§4.6 的"非法参数 → 400"精神）。当前不在本 PR 验收面内（验收只列了缺 agent/空文本/非法 model/已关闭 409）。
