# F03：默认模型与按角色覆盖

**功能 ID**: F03
**来源**: `demand.md` W4（TC-01 / G-6）；决策条款 D-7（默认模型 = `deepseek/deepseek-v4-flash`）
**迭代**: 0012-roles-agent-cluster

---

## 用户价值

角色实例默认使用 deepseek 模型（快、成本可控），不用每个角色单独交代；个别角色需要换模型时改配置即可，不碰代码、也不影响其他角色。

## 验收标准

1. **默认值**：未做任何模型配置时，角色实例的 LLM 调用使用 `deepseek/deepseek-v4-flash`（W4 / TC-01 / G-6）。
2. **按角色可覆盖**：集群配置文件中每个角色可写模型字段；为某角色写入一个模型后，该角色的 LLM 调用使用该模型（W4）。
3. **覆盖粒度隔离**：某角色被覆盖时，同一集群内未被覆盖的角色仍使用默认值——一次覆盖不改变其他角色的模型（W4）。
4. **解析优先级**：请求显式指定的模型优先于任何配置（沿用 0011 定稿链：请求 `model` > 环境变量 > 配置文件 > 内置默认）；按角色覆盖优先于全局默认值（W4 / 0011 定稿链）。环境变量与按角色覆盖的相对顺序见 AR-06。
5. **生效可观察**：模型覆盖经重启后生效，被覆盖角色可正常完成对话（回答正常产生）；该角色实际使用的模型标识可被观察到（判定面见 AR-07）。

## 边界（不包含）

- 不含模型不可用时的处置口径（沿用 0011 已定稿的"明确失败、不静默回退默认"；本卡不重开该决策）。
- 不含模型能力的对比评估、多模型路由、按任务类型自动选型（demand 未要求）。
- 不含模型费用的统计 / 配额 / 限流（demand 未要求）。
- 不含角色定义文件中的模型声明（F-3：角色 md 的 frontmatter 无模型字段；模型是实例参数，不是角色文件的属性）。
- 不含工具与 permission 的配置（F04 / F05）。
