| 项 | 待裁决内容 | 用户裁决 | 来源 |

## 因 P7 裁决产生的需求层后果（必须写进合同）

- **已知代价（用户明示接受）**：确认项默认阻塞无上限 ⇒ 无人看守时，触发确认的 agent 轮次会**保持等待状态**；本迭代**不提供**超时退化，策略化（默认选项 / 自动放行）列为后续迭代。
- 该代价与既有 `cluster.json` 的 `permission` 档（`allow` 档 = 恒放行）**并存**：本迭代把「该档位自动答复」改为「上浮给人」后，`allow` 档的语义在**有人值守**时改变（不再恒放行），无人值守时行为见上。
