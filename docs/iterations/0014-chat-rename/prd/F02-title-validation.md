# F02：标题校验（trim、100 上限、拒绝空值并恢复原值）

**功能 ID**: F02
**来源**: `demand.md` A-2（校验四条）；决策 D-2；澄清 M-3 / M-4 / M-9 / M-10（相邻项）；效果 E-5、E-6；边界 N-3 / N-4
**迭代**: 0014-chat-rename

---

## 用户价值

名字既说得清、又被约束住——不会出现空的、只剩空格的、或者长到显示不下的标题；手滑留了首尾空格也会被清掉，但自己打的空格原样保留。

## 验收标准

1. **保存前去除首尾空白，内部空白保留**：保存时对输入做首尾去空白后再落定；内部空白原样保留；"空 / 全空白"以去首尾空白后为空来判定（A-2 / M-01）`[model_inferred M-01]`。判定：输入 `"  季度复盘  "` 保存后标题为 `"季度复盘"`；输入 `"季度  复盘"` 保存后标题中间的两个空格不变。
2. **长度上限 100 字符**：手动标题最长 **100 个字符**，计数单位与既有自动生成的 40 字符截断**同一把尺子**（UTF-16 code unit，含 emoji / 组合字符等多单位字符按其所占单位数计）（A-2 / D-2 / M-4 / M-9 / E-6）`[user_confirmed 简报②③]`。判定：恰好 100 单位的内容可保存成功；101 单位的内容不可保存成功。手动上限 100 与自动截断上限 40 **并存、互不覆盖**（M-4 后半，自动侧见 F05 验收 1）。
3. **超过 100 字符时的反馈形态 = 编辑框硬上限**：输入达到 100 字符上限后编辑框不再接受更多字符（不产生超长中间态，已输入内容不丢失）（M-07 / `demand.md` §7 P-2 推荐值）`[model_inferred M-07]`。判定：持续输入超过 100 单位时，框内内容停在 100 单位、不出现可提交的超长内容；后续删除字符后可继续输入。
4. **空或全空白拒绝保存并恢复原值（不回退「新对话」）**：输入为空或全为空白时，保存被拒绝，标题**保持编辑前的原值**——既不是空串，也不是「新对话」（A-2 / D-2 / M-3 / E-5）。判定：对一条标题为「季度复盘」的对话，把输入清空（或只留空格）后保存，标题仍为「季度复盘」。
5. **拒绝后退出编辑态**：空 / 全空白被拒绝后，编辑框关闭，标题显示已恢复的原值（用户不需要再手动退出编辑）（M-02）`[model_inferred M-02]`。
6. **同一组校验规则在保存的完整链路上生效（不依赖单一入口）**：trim、非空、≤100 三项规则在保存链路上统一生效——即使不经过详情区编辑框提交标题变更，非法标题（空 / 全空白 / 超长）也**不会被写入**，标题保持不变（A-2 / `demand.md` §6 I-6；取值经阶段 2 简报确认）。判定：以编辑框之外的方式提交空标题 / 全空白标题 / 101 单位标题，读取标题均仍为提交前的值。

## 边界（不包含）

- 不含**编辑交互本身**（点击进入编辑、预选、Enter / 失焦 / Esc 的触发与优先级）——那是 F01。
- 不含**只读边界**——那是 F03；本卡只规定"允许提交的内容"，不规定"谁可以提交"。
- 不含**同步与排序**——那是 F04。
- 不做**清空标题**（N-4）——空值一律被拒绝，不存在"无标题对话"。
- 不做**自动生成规则的任何改动**（N-3）——40 字符截断、「新对话」兜底、首条输入定标题、`@agent` 前缀计入，全部保持现状（见 F05）。
- 不做**标题内容过滤 / 敏感词 / 字符集白名单**（demand 未要求）——除长度与空白规则外，任何文本内容均被接受。
- 不做**标题格式规范化**（大小写、全半角、标点转换等）（demand 未要求）。
