# F01：顶栏 agent 只读列表（点击展开、字段完整、只列在线、零写操作）

**功能 ID**: F01
**来源**: `demand.md` W3；澄清 M-1；效果 E1、E2、E9（界面部分）；边界 N1 / N2 / N3 / N5 / N10
**迭代**: 0015-hub-orchestration-open-api

---

## 用户价值

点一下顶栏那行「已连接 · N agents online」就能看到到底是谁在线、各自多久没有动静了，不用再切到终端敲命令；而且它只能看——点不出任何会改变现状的操作。

## 验收标准

1. **点击即可展开列表**：顶栏显示「已连接 · N agents online」的位置可点击；点击后展开 agent 列表，列表内容与该计数同源（同一时刻的在线实例集合）（W3 / E1）。
   *判定*：点击前后观察——点击前只有一行文字，点击后出现逐项列表；列表与计数在同一时刻指向同一集合。
2. **每项字段完整**：列表每一项呈现三项信息——**实例标识、在线状态、最后心跳时间**；最后心跳时间以**相对时间**表示（如「12s 前」）（W3 / M-1 / E1）`[user_confirmed MI-03]`。
   *判定*：逐项检查三项信息是否可见；抽 2~3 项，与另一终端执行的集群状态查询命令（`oamp status`）输出的对应实例逐项对照，实例标识与最后心跳时间一致；相对时间随列表更新而重算，不要求每秒跳动 `[user_confirmed MI-03]`。
3. **只列在线实例，且计数与条数一致**：列表中不出现任何已被判定离线的实例；**列表条数 = 顶栏计数 = 在线实例数**，三者始终一致（W3 / E2 / M-1）。
   *判定*：制造一个离线实例（停止一个 agent 并等待判活阈值过去），确认它不出现在列表中、计数也不把它算进去；对照集群状态查询输出的 online 集合，无多无少。
4. **只能看，不能做**：列表及其展开区域内不存在任何启动、关闭、断开 agent 的按钮、入口或操作（W3 / N1 / N2 / E9 界面部分）。
   *判定*：逐项检查列表及展开区域内的可见交互元素，启停类入口零命中。
5. **空态可判**：当前没有任何在线实例时，展开列表不出现任何实例条目、顶栏计数为 0，顶栏仍显示可点击的「已连接 · 0 agents online」（W3 / E2 的空集边界）`[user_confirmed MI-08]`。
   *判定*：停掉全部 agent（判活阈值过去后）展开列表观察。

## 边界（不包含）

- 不含**列表的自动更新**——那是 F02；本卡只要求"打开时看到的是对的"。
- 不含**离线实例的展示**：列表语义是"已连接的 agent"，判离线后即从列表消失（M-1），不做离线历史或"最近离线"提示。
- 不含 **agent 来源（本机拉起 / 外部连入）的判定与展示**（N3）——hub 无启动台账，无从判定。
- 不含 **agent 详情页 / 历史指标 / 空闲时长统计 / agent 级操作历史**（N10）。
- 不含**任何启动 / 关闭 / 断开 agent 的能力**（N1 / N2）——列表与其展开区域内零写操作入口。
- 不含 **tasks 相关展示**（N5）；顶栏既有的 Tasks 位置维持现状，不在本卡范围内。
- 不含**列表的收起方式与常驻形态**（再次点击 / 点击他处 / 独立页面 / 侧栏 / 浮层）——属架构维度。
- 不含**计数文案的变更**：沿用现状「已连接 · N agents online」与"在线实例数"口径（M-1）。

## 架构维度（阶段 3 已填，2026-09-12；详见 `architecture.md` §6.1 / §7.1 / §7.2 / §7.4 / §11 AR-01）

> 以下为阶段 3 定案；产品维度（用户价值 / 验收标准 / 边界）逐字未动。

- **AR-01-a 列表面板形态与交互**：**顶栏浮层**（下拉面板），锚定 `.topright`（`position:relative` + 面板 `position:absolute;right:0;top:100%`）。节点是 `.topright` 内、`#conn-status` **之后**的**静态兄弟节点** `<div id="agent-panel" class="agent-panel hidden"></div>`——不能做 `#conn-status` 的子节点，因为 `setConn()` 会写它的 `textContent`（`app.js:46-50`）。**展开** = 点击 `#conn-status`（仅已连接时可展开）；**收起** = 再次点击 / 点击面板与触发点之外的任意位置（`document` 级 click + `closest('#agent-panel, #conn-status')` 守卫）/ `Escape`；`setConn(false)`（Router 不可达）自动收起并隐藏。形态与既有 `#mention` 浮层同款（静态节点 + `.hidden` 切换，不动态创建）。
- **AR-01-b 字段呈现**：行 = 实例标识原文（`escapeHtml`）+ 在线状态徽标（复用既有 `badge()` 渲染器，映射新增 `online: 'badge-online'`；该字段按用户裁决保留，恒为"在线"）+ 最后心跳（新增 `fmtAgo(ms)`：< 60s → "Ns 前"、< 60min → "Nm 前"、否则 "Nh 前"）。排序**沿用服务端 `instance_id` 升序**（`snapshot()` 已排好，零客户端排序）。相对时间在**每次渲染时重算**（展开、事件到达、展开期 5s 刷新），**不要求每秒跳动**（MI-03）。
- **AR-01-c 数据获取**：复用既有 `GET /api/agents`（`loadAgents()` 在 `init` / `window.focus` / 面板展开期被调用），**响应形态零变更**——`registry.snapshot()` 仍只投影 `{instance_id, session_id, state, last_heartbeat}`（`last_heartbeat` 已是 epoch ms，无需新字段）。面板 = 前端对 `state.agents` 做 `state === 'online'` 过滤；`loadAgents()` **仍取全量**（面板与 `@` 补全共用 `state.agents`，`showMention` 的离线灰显行为不得被本迭代改变）。外部程序要"只在线"用 `GET /api/agents?state=online`（与面板同一口径）。条目新增字段不外泄（`snapshot()` 显式投影）。
- **AR-01-d 状态表现**：空态 = 面板内一行灰字 `暂无在线 agent` + 顶栏仍显示可点击的 `已连接 · 0 agents online`（MI-08 / 验收 5）；**不做 loading 态**（数据来自本机 UDS 的即时查询，无可见等待窗口——引入 loading 形同虚设）；Router 不可达时面板收起（避免展示失真列表），顶栏显示既有 `Router 不可达：…`。
