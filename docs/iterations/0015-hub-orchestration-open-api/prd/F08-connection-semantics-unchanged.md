# F08：连接与注册语义不变（回归约束）

**功能 ID**: F08

## 用户价值

这次加的都是「看」和「用」的通道，连接方式一点没变——已经在跑的 agent 不用改一行代码、不用重启，照常连上来。

## 验收标准

1. **连接方向唯一且 hub 不创建进程**：仍然只有「agent 主动连入 hub」这一种连接方式；hub 不主动连接、也不创建 agent 进程（W1 / N1 / N12）。
   *判定*：检查 hub 侧不存在创建 / 终止 agent 进程的行为；集群中的实例只以主动连入方式出现。
2. **注册 / 心跳 / 注销语义不变**：这三个动作的触发条件与语义保持现状（W2 / N7）。
   *判定*：既有 agent **不改代码**接入，注册、心跳上报、正常退出时的注销照常工作。
3. **实例标识校验规则不变**：合法的实例标识仍按既有规则（长度与字符集约束）被接受、非法标识仍被拒绝（W2 / N7）。
   *判定*：用既有合法标识接入成功；用越界 / 非法字符标识接入被拒绝，结果与迭代前一致。
4. **同名顶替规则不变**：同一实例标识重复注册时的顶替规则与对旧连接的处置通知保持现状（W2 / N7）。
   *判定*：用同一标识重复注册，观察结果与迭代前一致（旧连接被顶替、新连接生效）。
5. **既有拓扑查询语义不变**：另一终端的集群状态查询仍能列出节点及其**在线 / 离线**状态与实例标识（既有语义不变），并可作为 F01 的对照基准（W2 / F-9）。
   *判定*：查询输出仍包含在线与离线两类节点及其实例标识。
6. **既有 agent 零改动可接入**：既有集群命令拉起的 agent 与人工终端启动的 agent，都不改代码即可继续接入（W2 / F-7）。
   *判定*：不改任何 agent 代码启动一个实例，注册与心跳行为照旧。

## 边界（不包含）

- **不含心跳档位与判活阈值的联动取值**——那是 F03（W5③ / C-2）；本卡只锁连接与注册的**语义**不变，见 `prd.md` 疑问 1。
- **不含连接协议的新能力**：不新增"要求 agent 下线"等能力（N2 / N7；现状也确实没有该能力）。
- **不含鉴权与跨机连接**（N6）。
- **不改变 agent 进程的启动 / 停止方式**——仍由既有集群命令与人工终端承担，hub 不接管（N1 / N2 / N12）。
- 不含**心跳频率行为**本身（F03）——本卡只保证频率变化不破坏上述语义。
- 不含**接口面**的暴露与契约（F04 / F05 / F06）。
