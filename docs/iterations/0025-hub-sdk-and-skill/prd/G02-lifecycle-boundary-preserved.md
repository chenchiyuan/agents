# G02 · 生命周期边界保持 〔保证项〕

**功能 ID**: G02
**来源**: `demand.md` 第二段 §2 **N3**（不新增任何 agent 生命周期能力）、**N4**（不把启停能力搬进 hub 的 HTTP 面；封装 CLI 运维命令时零语义变更）；§4.4 **C-B**（划界：封装 ≠ 迁移；0015 N1/N2 约束的是 hub 不得承担生命周期）
**迭代**: 0025-hub-sdk-and-skill
**卡型**: **保证项**——不引入新能力，只承载"生命周期职责不进 hub / SDK 不自作主张"这一可独立核对的保证

---

## 用户价值

SDK **不把"启停 agent"这件事搬进 hub**，也不给 agent 加自愈——agent 的生命周期还是本机那个人说了算，不是某个守护逻辑说了算。

## 验收标准

1. **HTTP 面仍无启停路径**（N4）：hub 的接口清单里**不出现**启动 / 停止 agent 的路径或参数；启停仍只由本机既有 CLI 承担。
   *判定*：比对改动前后的接口清单 → 21 条不变且无启停类条目（与 [G01](G01-hub-interface-unchanged.md) 验收 1、4 交叉成立）。
2. **封装既有 CLI 命令零语义变更**（N4 / §4.4 C-B）：经 SDK 入口执行启停类命令，与**直接执行该 CLI 命令**的后果一致——不新增参数默认值、不改写行为、不改变现场。
   *判定*：对启停类命令各走两种入口 → 现场变化一致（见 [F04](F04-oamp-cli-command-coverage.md) 验收 2）。
3. **不新增生命周期能力**（N3）：SDK **不**提供守护、自愈、自动重试拉起、失败自动重派——失败就是失败，重试由调用方决定。
   *判定*：制造一次 agent 未运行 / 调用失败的场景 → 观察 SDK 或其接入面**不出现**自动拉起 / 自动重派的行为；命令以明确失败结束（→ [F08](F08-disconnect-degradation.md) / [F07](F07-exit-code-semantics.md)）。
4. **能力不因接入而被隐式转移**（N3 / N4）：既有的"生命周期归本机 CLI、hub 不承担"这一分工在改动后**可被同样描述**（不出现"现在 hub 也能停 agent"这类新事实）。
   *判定*：读改动后的接口声明与命令面 → 启停能力的归属与改动前一致。

## 边界（不包含）

- 不含既有 CLI 命令的**语义改动**（本卡只核"零语义变更"）。
- 不含"未来要不要做生命周期能力"的判断——**N3** 直接封死本迭代的"做"。
- 不含 0015 N1/N2 的**重解释**：本卡按 C-B 的划界原样保持（封装的边界 = 零语义变更地暴露既有本地命令）。
- 不含 SDK 的启动方式 / 常驻形态之类形态项（无待填项；本卡只核"没有额外能力"）。

## 架构落定（阶段 3）

> 架构维度结论；**产品维度（用户价值 / 验收标准 / 边界）逐字未改动**。详见 `../architecture.md` §5 / §4。

- **架构维度**：**无待填项**（保证项：约束是"不新增能力 + 不迁移职责"）。
- **落定（保证项的架构承载）**：
  1. **层 C = 子进程透传** ⇒ 不新增参数默认值、不改写命令行为、不改变启停现场（`../architecture.md` §5.1 层 C / L2-1）；
  2. **不提供任何自动性**：无自动重试、无自动重连、无自动心跳循环、无失败自动重派 —— `sdk/uds.js` 只暴露 1:1 的 `connect()` / `heartbeat()`（单次）/ `close()` 与其余 6 个方法（L2-9）；
  3. **HTTP 面零改动**：不新增启停路径或参数（G01 与本节交叉成立）。
- **与 F10 验收 4 的不冲突**：超时后"重新取终态"由**调用方**发起（重新调用，不是本地续等），与"SDK 不自动重试"互不冲突 —— 两者是"谁发起"的区别（N3 / C-D 的原意）。

## 越界自查

- **未做技术选型**：只核"有没有把能力搬过去 / 加进去"。
- 验收 3 的"自动重试"**与** [F10](F10-wait-timeout-limit.md) 验收 4 的"超时后重新调用"不冲突：前者禁止 SDK **自动**重试 / 重派，后者要求**调用方**可自行重新取终态——两者是"谁发起"的区别，均按 N3 / C-D 的原意落字。
- 未派生"集群健康检查 / 自愈策略"等功能（N3 已封死）。
