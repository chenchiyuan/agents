### 漂移注入（自撰，独立于被测用例）

在 `mktemp -d` 副本内，把 §3 首行 `GET /api/agents` 改为 `GET /api/agents__vfy_drift__`（后缀自取，非复用用例常量）：

```
对照臂（原文副本）        : pass=true  items=50
注入臂（改一个端点路径）  : pass=false items=51
非 ok 的 R1 项（恰 2 条） :
  {"id":"R1 GET /api/agents__vfy_drift__","ok":false,"expected":"GET /api/agents__vfy_drift__","actual":null,"reason":"登记缺失"}
  {"id":"R1 GET /api/agents","ok":false,"expected":null,"actual":"GET /api/agents","reason":"文档未覆盖"}
其余 R1 仍 pass : 20 / 20
R2 段不受影响   : 21 项 = 9 探 + 4 流式 skip + 8 写 skip
仓库 API.md     : sha256 df3839f0d7cb60ca70041e3fe77832cf75017481a5b5e8a19acaa1c64e24b563（注入前后逐字一致）
```

**结论**：一次路径注入**同时**命中「登记缺失」与「文档未覆盖」两方向，且两向都逐字点名端点 + 期望 / 实际 —— E2 裸判据（`demand.md` §4）成立。

### 零写副作用（行为证据 + 结构证据 + 线上证据）

**线上证据（最硬的一条）**：把 doctor 的端口指向我自建的 TCP 嗅探代理，抓到的**完整请求流水**只有 10 条：

```
GET /api/docs            (R1 的 1 次清单读取)
GET /api/agents          GET /api/chats          GET /api/chats/probe
GET /api/docs            GET /api/projects       GET /api/calls
GET /api/calls/probe/transcript                  GET /api/calls/probe
GET /api/confirmations   (R2 的 9 次探测)
```

- 非 GET 请求 = **0** ⇒ 8 条 POST 端点确实一次都没探（不是「探了但没写成功」）；
- 去重路径 = **9**，与 `API.md` §3 解析出的 9 条非流式 GET **逐条同集**，越界 = **0** ⇒ 4 条 SSE 端点确实一次都没探（不是「探了但很快断开」）。

**行为证据**：`projects / chats / agents / calls / confirmations` 五元读数前后 `deepEqual`；基线 `projects=1`（非空对空）。

**R3 零状态改变（非空注册表）**：先起一个真 agent 持续心跳，取投影 `nodes=[['pr010-vfy-1','online']]`、`tasks=[]` → 跑 `check()` → 再取投影：`deepEqual`，零新增节点 / 零新增任务。

**首轮 FAIL 的根因定位（自证伪）**：首轮 harness 在 `agents` 臂报了 1 次 FAIL。我没有直接下结论，而是写了一个精确 diff 脚本 `reads.mjs` 做三组对照：

```
[A] 无 agent 时：               diff = []                                   ← 零变化
[B] 我引入 agent 后：           diff = ["$.agents.agents[0].last_heartbeat: 1789467256860 → 1789467257777"]
[B 对照：不做 doctor，仅等待]  diff = ["$.agents.agents[0].last_heartbeat: 1789467257777 → 1789467258986"]  ← 与 doctor 无关
```

`/api/agents` 元素字段 = `[instance_id, session_id, state, last_heartbeat, role]`。**`last_heartbeat` 是我自己引入的活 agent 的心跳时间戳**，在不跑 doctor 的对照臂里同样会变 ⇒ 该 FAIL 是我的仪器噪声，**不是被测缺陷**。据此我改进了 harness（读数臂在引入 agent 之前取样），修正后 **39/39**。
