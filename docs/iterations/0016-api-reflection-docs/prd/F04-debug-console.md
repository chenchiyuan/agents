# F04：可交互调试台（表单生成、真实发送、订阅面板）

**功能 ID**: F04
**来源**: `demand.md` W3；决策 D-1 / D-5 / D-10；澄清 M-4 / M-6；效果 E4 / E6 / E8；边界 N1 / N6 / N9 / N12；约束 C-4；现状缺口 F-17（无任何调试页面）、F-21（既有"零启停入口"硬断言）；**用户确认（2026-09-12）：MI-02 / MI-03**
**迭代**: 0016-api-reflection-docs

## 用户价值

在页面上把接口**真跑一遍**：填几个字段、点一下发送，立刻看到真实的状态码、真实的响应内容和这次请求花了多久；订阅型接口也能挂上去，实时看着事件进来。

## 验收标准

1. **可达（顶栏入口 + 独立地址）**：控制台顶栏有"调试"入口，点击进入调试台；该页同时有**独立地址**，直接输入地址也能打开（D-5 / D-10 / M-6 / E8）。
   *判定*：从控制台顶栏点一次 + 手动输入地址一次，两次都能打开该页。
2. **覆盖登记中全部接口**：调试台列出的接口集合与路由登记的接口集合**一致（不多不少）**，包含两条订阅型接口（M-4 / C-4）。
   *判定*：两个方向的集合求差均为空。
3. **表单按元数据生成**：选中接口后按其元数据生成输入控件——无参数接口直接可发送；带查询参数的接口生成对应输入框；带路径参数的接口生成输入框；有请求体的接口**按字段类型**生成控件（文本 / 数字 / 布尔 / JSON）（M-4）。
   *判定*：分别取"无参 / 带查询参数 / 带路径参数 / 带多类型请求体"四类接口，逐字段核对生成的控件与该接口字段一一对应。
4. **发送并展示真实响应**：点击发送后，页面展示**真实**的 HTTP 状态码、响应体与耗时（毫秒）；请求确实到达服务并按该接口语义生效（W3 / E4）。`[user_confirmed MI-02：「耗时」= 从请求发出到完整响应到达的墙钟毫秒数，含传输与处理、不含界面渲染]`
   *判定*：发送一个只读接口，对照其状态码与响应体；再发送一个写接口，在控制台对应位置确认效果**真实出现**（例如对话列表中出现该对话）。
5. **订阅面板**：对两条订阅型接口，页面上可建立订阅并**按到达顺序实时展示事件**（含事件名与关键内容）（M-4 / E6）。`[user_confirmed MI-03：面板除建立与查看外，可主动停止订阅]`
   *判定*：订阅全局事件，在另一终端启动 / 停止一个 agent，面板按序出现对应的上线 / 下线事件。
6. **不硬编码登记之外的接口**：接口清单与表单**完全来自登记处**，页面上不出现登记之外的任何路径、也不出现任何"快捷操作"式入口（C-4 / N9）。
   *判定*：逐项与登记集合比对 + 全页检索登记之外的路径与 agent 启停入口，零命中。
7. **无痕**：不做请求历史持久化、收藏、环境变量集、批量 / 脚本化请求、只读模式总开关（N6 / P-7 / P-8）。
   *判定*：刷新页面后此前发出的请求记录不保留；页面检索上述入口，零命中。

## 边界（不包含）

- **不含请求历史持久化 / 收藏 / 环境变量集 / 批量与脚本化请求 / 只读模式总开关**（N6）。
- **不含 agent 启停能力**（N9）——页面只渲染登记中存在的接口，登记里没有该能力。
- **不含写操作防护**——发送前确认、危险标识、页面级风险提示归 F07（本卡只保证"能发、看得见真实结果"）。
- 不含接口文档页的字段说明展示（→ F03）。
- 不含鉴权、多用户、凭据与跨机请求（N1）。
- **不把新页面的脚本 / 样式资产并入既有控制台页面资产**（N12）。
- 不含面向 AI 的索引文件的内容与生成（→ F05）。
- 不含漂移锁（→ F06）。

## 架构落定（阶段 3；完整契约见 `architecture.md` §5.1 / §6）

- **AR-04-a 承载方式与页面文件划分**：**静态文件 + 客户端渲染**：`oamp/web/debug.html` + `oamp/web/debug.js`（新文件，不并入既有控制台资产，N12）；经静态面以独立地址 `/debug` 提供；与文档页共享 `api-pages.css` 与 `GET /api/docs` 数据源，不共享 JS。
- **AR-04-b 取数与表单渲染实现**：页面加载时 `fetch('/api/docs')` → 渲染接口清单 → 选中后按 `params[]` 生成控件（`in` 决定位置、`type` 决定控件、`enum` 决定下拉）；发送时**路径参数** `encodeURIComponent` 代入 URL、**查询参数** 交 `URLSearchParams`、**请求体** 组装对象后 `JSON.stringify`。空值策略：未填且非必填 → 不发该字段；未填但必填 → **照发**（拿服务端的真实 400/404，不在前端拦截）。接口清单与表单**完全来自投影**（验收 6）。
- **AR-04-c 耗时的测量与展示（MI-02 落地）**：`performance.now()` 取两次（发出前 / 读完响应体后），差值为 **墙钟毫秒（含传输与处理、不含渲染）**，`Math.round` 取整；与状态码、响应体同区展示"状态码 · N ms"。
- **AR-04-d 订阅面板实现（含 MI-03）**：`kind === 'sse'` 的接口渲染"订阅 / 停止"控制与事件日志区；`new EventSource(url)`（`/api/stream` 的 `chat_id` 由参数输入框拼入 URL；`/api/events` 无参直连）；事件按到达顺序**追加**展示（事件名 + data 原文，可解析则美化）；**停止 = `es.close()`**。与发送区**互斥显示**（同一接口不同时提供两种操作）。
- **AR-04-e 防护挂载点**：发送函数内**唯一一处** `if (route.danger && !window.confirm(...)) return;` —— 防护不逐接口手写；`danger` 由 `method` 派生（见 AR-07-c）。与订阅区无关（SSE 均为 GET）。
- **AR-04-f 样式落点**：共用 `oamp/web/api-pages.css`（表单/日志/结果框类名），复用既有 `:root` token；两页同时 `<link>` 既有 `/style.css`；既有样式文件除 1 条 `a.nav-item` 规则外零改动。

**不做的**：无请求历史/收藏/环境变量集/批量脚本化/只读总开关（验收 7、N6）；无 agent 启停入口（N9）；无 localStorage 等任何跨刷新留存。
