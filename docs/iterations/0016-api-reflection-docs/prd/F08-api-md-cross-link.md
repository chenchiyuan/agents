# F08：与契约文档互补共存 + 双向互链

**功能 ID**: F08
**来源**: `demand.md` W7；决策 D-4 / D-8；澄清 M-8；约束 C-2；边界 N7 / N10；现状事实 F-16（同一份接口清单已存在三处副本）；**用户确认（2026-09-12）：MI-04**

## 用户价值

想快速查字段去文档页，想看使用场景和能直接复制的例子去 `API.md`；两边互相点得到，而且说的是同一件事——不会出现"两个地方说法不一样、不知道信哪个"。

## 验收标准

1. **契约文档保留人工叙述与示例**：`API.md` 继续承载叙述、使用场景与可粘贴示例，**不被自动化替换、也不从登记处重新生成**（W7 / D-4 / N7）。
   *判定*：检查该文档仍由人工维护的叙述与示例构成；接口登记变化不会覆盖或重写它。
2. **契约文档的路径级登记义务**：登记中新增路由后，`API.md` 中出现该路由的**路径**——**一行即可**，不要求写章节、参数或示例（C-2 / D-6）。
   *判定*：新增一条登记 → 在 `API.md` 中可检索到该路径；该义务由 F06 验收 3 强制。
3. **契约文档顶部指向文档页**：`API.md` 顶部有指向接口文档页的链接（W7 / M-8）。
   *判定*：打开文档顶部即可点击进入接口文档页。
4. **文档页逐接口指向契约文档**：接口文档页的**每个接口**都有指向 `API.md` 的链接（W7）。`[user_confirmed MI-04：链接粒度＝优先指向该接口在 `API.md` 中的专属位置；当该接口仅有路径登记时，指向该路径所在位置；锚点形态属 AR-08]`
   *判定*：逐接口在文档页检索该链接并可点开。
5. **文档页不复制契约文档的叙述与示例**：文档页只承载结构与字段的派生视图（含响应形态说明），不出现从 `API.md` 抄来的叙述段落与可粘贴示例（M-8 / D-8）。
   *判定*：逐页检索叙述段落与示例报文，零命中（与 F03 验收 4 互为补充面）。
6. **分工可辨且两边不冲突**：任一接口的"结构与字段"在文档页可查、"为什么这么用 / 怎么用"在 `API.md` 可查；两边对同一接口给出的事实（方法 / 路径 / 参数名 / 错误码）**一致，无相互矛盾**（M-8 / D-4）。
   *判定*：抽取若干接口两边对照，逐项事实一致。

## 边界（不包含）

- **不含 `API.md` 的自动化重写或从登记处重新生成**（N7）。
- **不含把文档页做成第二份叙述副本**（M-8）。
- 不含文档页的搜索 / 全文索引 / 富交互（N10）。
- 不含把 `API.md` 的文案纳入硬锁——只锁路径集合（C-2 / D-6）。
- 不含 README 等其它既有文档的重构（属实现成本，见 `prd.md` 的 AR-09）。
- 不含索引文件内容（→ F05）与漂移锁本身（→ F06）。

## 架构落定（阶段 3；完整契约见 `architecture.md` §6.7 / §9.1）

- **AR-08-a 契约文档顶部链接的位置与形态**：`oamp/API.md` 在 **H1 与引言段之后**追加一行引用块：`> 在线接口文档页：<http://127.0.0.1:7788/docs>（字段级结构视图；本文件保留叙述、使用场景与可粘贴示例）` —— 首屏可见、不改既有引言段（验收 3）。
- **AR-08-b 文档页逐接口链接的锚点形态**：表项 `docLink` = **相对 URL + 章节锚点**（GitHub 风格 slug：小写、去 `.`/`/`/反引号、空格→`-`，如 `API.md#37-post-apichatschat_idrename`）；文档页逐接口渲染 `<a href="{docLink}">API.md</a>`（验收 4）。**MI-04 的"仅有路径登记"情形**：`docLink` 指向该路径所在位置的锚点（若该路径只有一行、无独立小节，则写该行所属小节的锚点）。已知局限：`API.md` 以 `text/plain` 提供 ⇒ 链接可点开但不自动滚动到章节（诚实标注，`architecture.md` §13 R-3）。
- **AR-08-c 新增路由在 `API.md` 的登记格式**：**反引号包裹的 `METHOD /api/<path>`**（占位符 `<param>` 的拼写任意，`?查询串` 可带）——这是漂移锁③可识别的唯一形态。实例：列表项「短横线 + 反引号内的 `POST /api/x/y`」，或 §3 清单表的一行。**约定**：文档中的反例/边界说明不得写成该形态（否则被判为"未登记路径"），建议写成不带反引号的散文或带"不提供"前缀的说明。本轮需为新增的 `GET /api/docs` 补这一行 + 一个 `### 3.11` 小节，并把 §3 标题的"10 条"改为"11 条"（`architecture.md` §9.1）。
