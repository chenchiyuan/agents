### 标准 2：API 行为（自建隔离环境复现）

**pass**（30 条断言全部为真，逐条见下）

自建隔离环境（临时 socket + 临时 SQLite + 随机端口 49xxx + 进程内假节点 ×2，脚本与日志位于本验证者临时目录，验收后已删除）。逐条断言结果：

## 下一迭代候选

> 本轮发现的优化点、边界问题或遗留限制。不在当前验收标准范围内，供主 agent 与 planner 决定是否纳入下一迭代。

- **归档视图无「已加载 N / 共 M 条」进度提示**：`#load-more-slot` 只在 `chats.length < total` 时出现按钮，用户无法知道还有多少条。数据量大时（>200）多次点击体验偏盲。当前 F04 未要求，属 UX 优化点。

- **无单条归档入口**：架构 §5.1 候选 D 已判定 YAGNI（产品无触发点）。若后续出现「归档某一条」需求，需同时补 API 与 UI 触发点。
