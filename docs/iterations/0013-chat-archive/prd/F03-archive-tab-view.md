## 用户价值

所有收起来的对话集中在一个地方，最近收起的排最前，一眼看到还不算完——每一项旁边就有把它捞回来的入口。

## 验收标准

1. **归档标签页入口**：过滤栏新增「归档」标签页，与既有 All / Working / Completed 并列（D-3）。判定：过滤栏可见「归档」这一可选项，选中后进入归档分类视图。
2. **内容与主列表互斥**：归档视图**只**列出已归档对话；主列表（All 及各状态过滤）**不再显示**任何已归档对话（M-8 / C-3）。判定：同一条对话归档前出现在 All，归档后只出现在归档视图、不再出现在 All。
3. **归档时间倒序**：归档视图按归档时间倒序排列——最近归档的排最上（D-4）；归档时间相同的项按对话标识倒序排列，保证顺序稳定可复现（A-3）。
4. **列表项构成**：每一项显示该对话的标题、所属 agent、归档时间，以及其归档时的原状态标识（D-13 / M-3）。
5. **每项带独立可点的「激活」按钮**：每一项都有「激活」按钮；点击该按钮**不**打开该对话详情（不触发行点击行为），而是进入激活动作（D-13 / M-4）。判定：点击按钮与点击该行其他区域产生不同结果——前者不打开对话详情。
6. **空态**：没有任何已归档对话时，归档视图显示"还没有归档的对话"（A-10）。
7. **归档时间可读且可区分先后**：归档时间以用户可读的形式展示，足以区分不同项归档的先后（格式沿用既有列表的时间展示方式）`[model_inferred M-02]`。

## 边界（不包含）

- 不含触发归档的入口与批量编排（F01）、单条归档的语义（F02）、激活执行本身（F05）——本卡只规定"归档视图长什么样、列出什么、按什么顺序、如何进入"。
- 不含归档数量超过单页容量时的可达性——那是 F04；本卡在归档总数不超过单页容量时即应全部正确列出。
- 不做**归档专属的搜索 / 时间过滤维度**（N-6）——沿用既有 q / agent 过滤能力，不新增归档专属过滤维度。
- 不做**归档项的手动排序 / 排序自定义**（N-7）——排序固定为归档时间倒序。
- 不做**批量激活**（N-3）——归档视图内的操作只有"打开查看"与"单个激活"。
- 不做**多用户 / 权限**（N-8）。
- 不含归档视图的自动刷新 / 轮询（demand 未要求）。
