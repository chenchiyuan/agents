从已确认的 **why** 反推 **what**：

**⇒ 本迭代的两件交付物（清理 + 协议）必须在同一次迭代内闭合。** Q13/Q14 均选 A（协议包含验收口径与重建触发条件）确认了协议 ∈ 本迭代；此条登记为交付前置条件，不构成阻塞。
