# F06 · 测试协议 · 阶段 6 零测试态独立取证口径

**来源**：demand.md 做什么 W-3 第 4 条后半；结论 Q13；§5 影响面表第 5 行；§3「大概怎么做」（阶段 6 无保留集时自写临时脚本实测 + 报告显式声明「本次无跨迭代回归证据」）

## 用户价值

无回归套件可跑时，独立验证仍拿得到实证（自写临时脚本实测），同时"本次没有跨迭代回归证据"这件事被写进报告而不是静默消失——读报告的人不会误以为回归面已经被覆盖。

## 验收标准

1. 协议中明确：无保留集时，阶段 6 的独立取证只能靠自写临时脚本做实测。
2. 协议中明确：这种情况下阶段 6 报告**必须显式声明**「本次无跨迭代回归证据」（原文或等价的无歧义表述），该声明不可省略——不得静默为"验证通过"。
3. 协议中明确该声明与 pass / fail / partial / blocked 结论的关系：声明本身不改变结论（缺回归证据不等于 fail），但缺声明即报告不合格。
4. 自写临时脚本的落点与删除遵守 F04 的一次性脚本规则（跑完即删）。
5. 该约束带 `判断方式：…`（形态见 [F08](F08-protocol-judgeable-constraints.md)）：拿一份阶段 6 报告，能判定它是否满足第 2 条。

1. **"缺回归证据不等于 fail"**：demand.md §3 只写了"报告必须显式声明「本次无跨迭代回归证据」"，未写该声明与结论的关系。本卡从"零测试交付是用户已确认的既定状态"推导：既然没有回归套件是设计决策而非缺陷，缺回归证据本身不应被判定为验证失败；但缺声明属报告质量问题。依据：Q8 + Q14 + §2（零测试交付为既定终态）。**待主 agent 确认。**
