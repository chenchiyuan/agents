# pr-001-workflow-pb-workspace-isolation-protocol

## 上下文摘要

规范 v0.8.0 → v0.9.0 / SKILL v1.11.0 → v1.12.0：新增规则 C~G（会话工作区隔离、启动契约、分支命名、跨工作区写入禁止、暂停终止现场保留）+ 隔离边界声明 + 角色定义来源与部署；规则 A/B 术语限定为 PR worktree；启动工作流 4.5 的建分支动作声明为已完成（Q-1=A）；brief 三处路径改 `{角色定义根}`；阶段 5 落点具体化；收口改 `git -C <仓库主工作区>` 并加前置游离；文档路径相对会话工作区根。SKILL 侧同步来源契约、Step 0 启动校验与 32 处路径引用；两侧 changelog / memory / skill-optimization 随版本落盘。

## 涉及功能点

- F01（会话工作区形态：worktree 默认且唯一被规范化、clone 只作兜底声明）
- F02（每迭代一个工作区、绑定并全程保持迭代分支）
- F03（启动契约与硬停：三条判据 + 发现即停 + 约束主体）
- F04（指代重载：根目录 → 会话工作区根目录、主工作区声明、相对路径判读主体）
- F05（合并固定在仓库主工作区、会话工作区永不 checkout main）
- F06（分支命名必须含迭代编号、PR 分支规范化、base 与合并目标不变）
- F07（父子层声明、PR worktree 定位、术语不歧义）
- F08（角色定义来源 = 被追踪内容、`.pb-agents/` 与安装脚本降级为可选分发、两场景共用同一份规范；**本卡验收 3 是跨规范/SKILL 判据，故两文件同 PR**）
- F09（跨工作区写入禁止：三类写操作 + 闭集例外 + "不可能被 git 强制"）
- F10（暂停 / 终止迭代的现场保留，与既有失败/阻塞 PR 条款并列不冲突）
- F11（非 git 共享资源声明 + 两条约束）
- F12（隔离边界声明：覆盖 / 不覆盖 / 已知代价 / 不夸大）
- F13（规范形态约束：零工具依赖 + 每条条款自带判断方式 + 不引入守卫）
- F14（既有条款零破坏：零改动清单 + 生效范围 + 不改 `oamp/**`）
