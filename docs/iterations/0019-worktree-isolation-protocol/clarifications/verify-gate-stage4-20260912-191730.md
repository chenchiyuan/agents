## 3. 验证标准（委托内联，逐条复述）

1. **格式规范**：每个 PR 文件含且仅含七字段（上下文摘要 / 涉及功能点 / 文件范围 / 验收标准 / 参考资料 / depends_on / batch），字段名与体例符合规范。
2. **PR 粒度判断框架**（逐 PR）：逻辑原子性 / 可审查性 / 独立性，各给判断与依据。
3. **依赖正确性**：① `depends_on` 每条声明的可核实证据（空集是否合理）；② 依赖图无环；③ PR 间文件范围无重叠（逐文件核对真交集）；④ `prd/*.md` 每个功能点 F01~F15 被至少一个 PR 引用，无遗漏无多余编号。
4. **与 architecture.md v1.2.0 一致性**：逐 PR 核对文件范围与验收标准 vs §5（W1~W19 / S1~S10 / 零改动清单 / 惯例文件同步）——有无遗漏变更项、有无把零改动面列入 PR、有无超出变更面的改动用例。
5. **交付前置条件**：PR 文件是否足以支撑阶段 5（验收标准可否直接执行判定；是否存在必须先由主 agent 裁决的阻塞项）。
