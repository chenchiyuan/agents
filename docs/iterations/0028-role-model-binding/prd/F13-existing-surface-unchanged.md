# F13 · 既有面零改动与既有语义保持（**保证项**）

**来源**：demand.md §不做什么（第 5 条"不改 per-call `model` 的既有语义"）；§大概怎么做（"生效链路（既有、不改）"）；决策 D-5

> **本卡不引入任何新能力**：它只把 `demand.md` 已确认的既有面约束变成一条可独立验收的载体（体例先例：0018 的 F14~F16）。

## 用户价值

这次只往配置里写两行、跑一串验证，**不动任何运行时代码**——任何人 review 时都能用一条改动清单确认"没有顺手改实现、没有把既有语义带走样"。

## 验收标准

1. **改动面清单可核对**：迭代分支相对 main 的改动路径只含 `cluster.json` 与迭代产物 `docs/iterations/0028-role-model-binding/**`；**不含** `oamp/src/**`、`oamp/web/**`、`oamp/bin/**`、`oamp/sdk/**`、`oamp/README.md`、`oamp/API.md`、`roles/**`（判据 = `git diff --name-only` 的路径清单逐项比对）。该清单同时锁死"不新增接口 / 字段 / 参数"这条全局约束——取证与派发全程只能使用既有面（新增面必然要求改 `oamp/**`），各卡的取证要求据此成立，不另立重复条款。
2. **per-call `model` 的既有优先级语义保持**：存在至少一条调用，其派发携带 `--model`、目标角色在当前集群配置中**无** `model` 绑定，且实报 `model` 与请求值解析到同一后端（证明请求参数仍优先于全局默认，既有解析链语义未被改写）。**证据复用 F02 的两条常驻探针回执**（本卡不重复取证）。

## 边界（不包含）

- **不清理 0027 迭代现场**（规则 G：worktree 与分支原样保留）。
- 不修改 `demand.md`（红线）。
- 不修复与本迭代无关的既有缺陷——例如 C-1（默认 id 与 provider 清单不同名、靠 fuzzy 解析）：只记录（F12），不修。
- 不新增测试、CI、git hook 或第三方依赖（本迭代的验收由证据承担）。
- 不把本卡当作"任何文件都不许动"的宽泛约束：`cluster.json` 与迭代产物是本迭代的正当改动面（F03 / F12）。

无待填项（本卡是对既有事实的冻结，不涉及技术选型 / 数据模型 / 接口设计）。
