## 用户价值

拿到简报的人不用猜"产物该放哪儿"——简报里就写着该工作区的绝对地址，所有产物路径照着它判读就行。

## 验收标准

1. **简报携带工作区绝对地址**（W12 / E2）：派发简报中出现该会话 / 该 PR 工作区的**绝对地址**。
   *判定*：任取一份派发简报，检索其中是否出现该工作区的绝对地址 → 未出现即不通过。
2. **产物路径以该地址为根**（W12 / E2）：简报里给出的产物路径**可据此解析**，不依赖读者猜测 cwd。
   *判定*：取同一份简报，把其中每条产物路径按声明的地址解析 → 全部可解析即通过；出现无法定位的路径（必须靠猜 cwd）即不通过。
3. **相对路径不得作为唯一寻址方式**（W12）：简报与条款中，相对路径**不得是唯一**的定位手段。
   *判定*：读条款 + 取一份简报核对 → 存在只能靠相对路径定位的产物即不通过。
4. **文档路径协议基准句改写**（W12）：基准句由"该会话所在的**迭代工作区根目录**"改为"**该会话声明的工作区地址**"。
   *判定*：读改动后的基准句 → 仍以"会话所在目录"为基准即不通过。
5. **两级分层的指代关系可读**（W12 / W11 关联）：简报是**投影 2**；与源（产物）不一致时**以源为准**（裁决规则见 F07 验收 2）。
   *判定*：读简报纪律条款中的指代关系 → 未指向 F07 的裁决规则即不通过（不由本卡重复定义裁决规则）。
