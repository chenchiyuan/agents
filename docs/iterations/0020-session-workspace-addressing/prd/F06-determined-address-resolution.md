## 用户价值

谁都能算出"我这个迭代的工作区在哪儿"——不靠猜、不靠问、不看当前目录，换个人换台机器算出来是同一个。

## 验收标准

1. **默认可确定性推出**（W10）：工作区地址**默认**由「**迭代 ID** + **仓库主工作区**」推出——**不依赖 cwd、不依赖用户输入**。
   *判定*：在**两个不同的 cwd**（例如仓库主工作区与其下任一子目录）分别按该推导规则求值 → 结果必须**相同**；同一迭代 ID 求值必须**唯一** → 出现结果随 cwd 变化、或同一输入有两个结果即不通过。
2. **允许显式输入覆盖**（W10）：默认推导之外**允许显式覆盖**。
   *判定*：读条款 → 出现"只允许默认值 / 不允许指定"即不通过。
3. **覆盖后的地址仍进入声明链**（W10 / W11 关联）：显式覆盖发生时，被覆盖后的地址仍进入三层声明（源 / `status.md` / 简报）。
   *判定*：读条款的关联表述 + 一次覆盖场景的三处比对（与 F07 验收 2 同源） → 覆盖后的地址未进入声明链即不通过。
4. **失败面归属唯一**（W10 / W13 关联）：当仓库主工作区无法确定、或工作区无法创建时，进入**唯一硬停面**（→ F09）；本卡**不新增其他失败面**。
   *判定*：读条款 → 出现"当前目录不是工作区即停止"之类以 cwd 为触发面的停止条件即不通过。
5. **cwd 不出现在推导链中**（W10 / W2 关联）：推导过程不读取 cwd。
   *判定*：读条款与（阶段 3 的）实现描述 → cwd 作为输入项出现即不通过。

## 边界（不包含）

- **不含解析命令的具体写法**（N6 → T-03）：本卡只要求"可确定性推导 + 可覆盖 + 不依赖 cwd 与用户输入"。
- **不含"仓库外任意 cwd"的保证**（N8）：仓库外情形不在本迭代范围（`demand.md` §7 已登记该项为 `[UNVERIFIED]`，本阶段未据此新增保证）。
- 不含工作区的**建立**动作（→ F01 验收 3）。
- 不含地址声明落在哪三处、如何裁决不一致（→ F07）；不含简报表述（→ F08）。
- 不含分支名与迭代编号的关系（既有条款不变，→ F13 验收 2）。
- 不含任何工具依赖（N3 → F21）。
