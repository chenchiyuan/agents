# F06：工作区地址确定性解析（默认推导 + 可覆盖）

**功能 ID**: F06
**来源**: `demand.md` 第二段 §2 **W10**（`user_confirmed`：P-5① 按推荐）；第一段 M-2 已闭合（「worktree 定义到指定路径」的施动者与形式 = 默认确定性推导 + 可显式覆盖）；边界 **N8**
**迭代**: 0020-session-workspace-addressing
**产品对象（引用 `demand.md` 只读事实，非本阶段决策）**: 既有工作区落点事实 `<仓库主工作区>/.pb-agents/worktrees/{迭代ID}`（F15）；既有「规则 E：分支名含迭代编号」

---

## 用户价值

谁都能算出"我这个迭代的工作区在哪儿"——不靠猜、不靠问、不看当前目录，换个人换台机器算出来是同一个。

## 验收标准

1. **默认可确定性推出**（W10）：工作区地址**默认**由「**迭代 ID** + **仓库主工作区**」推出——**不依赖 cwd、不依赖用户输入**。
   *判定*：在**两个不同的 cwd**（例如仓库主工作区与其下任一子目录）分别按该推导规则求值 → 结果必须**相同**；同一迭代 ID 求值必须**唯一** → 出现结果随 cwd 变化、或同一输入有两个结果即不通过。
2. **允许显式输入覆盖**（W10）：默认推导之外**允许显式覆盖**。
   *判定*：读条款 → 出现"只允许默认值 / 不允许指定"即不通过。
3. **覆盖后的地址仍进入声明链**（W10 / W11 关联）：显式覆盖发生时，被覆盖后的地址仍进入三层声明（源 / `status.md` / 简报）。
   *判定*：读条款的关联表述 + 一次覆盖场景的三处比对（与 F07 验收 2 同源） → 覆盖后的地址未进入声明链即不通过。
4. **失败面归属唯一**（W10 / W13 关联）：当仓库主工作区无法确定、或工作区无法创建时，进入**唯一硬停面**（→ F09）；本卡**不新增其他失败面**。
   *判定*：读条款 → 出现"当前目录不是工作区即停止"之类以 cwd 为触发面的停止条件即不通过。
5. **cwd 不出现在推导链中**（W10 / W2 关联）：推导过程不读取 cwd。
   *判定*：读条款与（阶段 3 的）实现描述 → cwd 作为输入项出现即不通过。

## 边界（不包含）

- **不含解析命令的具体写法**（N6 → T-03）：本卡只要求"可确定性推导 + 可覆盖 + 不依赖 cwd 与用户输入"。
- **不含"仓库外任意 cwd"的保证**（N8）：仓库外情形不在本迭代范围（`demand.md` §7 已登记该项为 `[UNVERIFIED]`，本阶段未据此新增保证）。
- 不含工作区的**建立**动作（→ F01 验收 3）。
- 不含地址声明落在哪三处、如何裁决不一致（→ F07）；不含简报表述（→ F08）。
- 不含分支名与迭代编号的关系（既有条款不变，→ F13 验收 2）。
- 不含任何工具依赖（N3 → F21）。

## 架构落地（阶段 3 已填，见 `architecture.md` §5.2（6 步表）+ §8.1-D（条款全文）+ §12 的「口径注记」；产品维度未改一字）

- **T-03 命令序列（不读取 `pwd`、不使用启动目录作为输入项）**：① 仓库主工作区 = `git rev-parse --path-format=absolute --git-common-dir` 输出的**父目录**（该值在同一仓库的任意位置求值相同 ⇒ **两个不同位置求值结果相同**，这就是本卡验收 1 的核对方式；**不是** `--show-toplevel`、**不是** `pwd`）；② 工作区地址 = `<仓库主工作区>/.pb-agents/worktrees/{迭代ID}`（输入项 = 迭代 ID + 共享 `.git` 的绝对路径）；③ 建立（仅当地址不存在）= `git -C <仓库主工作区> worktree add .pb-agents/worktrees/{迭代ID} -b iteration/{迭代ID} main`；④ 成功 / 存在性依据 = `git worktree list` 含该地址 + `git -C <该地址> branch --show-current` 输出 `iteration/{迭代ID}`。
- **显式覆盖的输入形态**：派发简报的 `工作区地址：<绝对路径>` 字段（**投影 2**，优先级高于默认推导）；覆盖后的地址仍进入声明链——写入 `status.md` 的 `**工作区地址**` 字段（投影 1）并出现在此后简报中（本卡验收 2、3）。
- **"主工作区"求取方式的不可变性依据**：`--git-common-dir` 是**仓库级不变量**（0019 已用它做层级判据，`architecture.md` §1.2-B）；条款明写"取值与本会话的启动位置无关"。
- **失败面归属唯一（本卡验收 4）**：主工作区无法确定（仓库外 / 非 git）或建立失败 → **唯一硬停面**（`architecture.md` §5.4）；条款中**不出现**任何以 cwd 为触发面的停止条件。
- **口径注记（如实声明，供阶段 6 复判）**：解析经由 git 自身的仓库发现，进程起点仍是会话的启动位置；条款的准确含义 = **cwd 不是地址的输入项、也不影响结果**，且 `pwd` / `--show-toplevel` 在新增 / 改写条款中 0 出现（`architecture.md` §12）。
