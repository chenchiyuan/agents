## 验收标准

1. **worktree 仍是唯一被规范化的形态**（W17）：会话 / 迭代工作区与 PR worktree 仍以 worktree 形态承载；不引入第二种形态、不取消 worktree。
   *判定*：读改动后的规范 → 出现 worktree 之外的形态被规范化、或 worktree 被降级为可选，即不通过。
2. **五项骨架逐条保留**（W17 / N1）：① 每迭代一个工作区；② 阶段 1~6 期间检出 `iteration/{迭代ID}`；③ PR worktree 为该迭代工作区的**子层**；④ 分支名含迭代编号；⑤ 工作区落点形态不变（`.pb-agents/worktrees/` 下的布局）。
   *判定*：逐条对比改动前后的对应文本 → 任一条发生变化即不通过。
3. **变更面闭合、无越界改写**（N1 / N2）：本迭代对规范与 SKILL 的**全部改动逐条可追溯**到本迭代的某个承载卡（F01~F12、F14~F21 所承载的 W / E / N 条款）；**不存在与"判据形态与载体"无关的改写**。
   *判定*：取改动前后的文本 diff，逐条归类到某张卡 → 出现无法归类的改动即不通过。 〔核对组织与基线 → T-13〕
4. **阶段序列与推进条件零变化**（N2）：阶段序列（6 阶段）、各阶段职责、各阶段推进条件、并发槛位算法（起始 / 硬上限 / 爬升公式）、PR 文件**七字段格式**逐条不变。
   *判定*：逐条对比改动前后的对应文本 → 任一条发生变化即不通过。
5. **不改 `oamp/` 产品代码**（N4）：本迭代产出中**不含**对 `oamp/**` 的任何改动，也不新增任何脚本文件。
   *判定*：取本迭代的改动文件清单 → 出现 `oamp/**` 或新增脚本即不通过。
6. **生效范围：不追溯已完成迭代**（N5）：规范条款**从下一个迭代起生效**，不追溯已完成迭代；**0018 的文件零改动**（其活指令的处置见 F16）；不新增任何清理动作（N9）。
   *判定*：读生效范围声明 + 改动文件清单 → 出现追溯适用表述、出现 `docs/iterations/0018-*/**` 的改动、或出现清理条款，即不通过。
7. **既有护栏条款不被削弱**（既有条款）：既有 CRITICAL 与既有规则中与寻址无关的护栏（如"阶段 1 不可跳过""用户决策点必须暂停""不得对失败 / 阻塞 PR 清理现场""不修改执行角色产物内容"等）逐条保持。
   *判定*：逐条对比改动前后的 CRITICAL 与规则清单 → 出现删除或语义放宽即不通过。
