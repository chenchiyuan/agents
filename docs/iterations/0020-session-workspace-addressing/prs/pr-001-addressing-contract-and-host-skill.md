# pr-001-addressing-contract-and-host-skill

## 上下文摘要

把「会话必须在自己的会话工作区里启动」换成「会话声明工作区绝对地址并按地址显式寻址」：规范 v0.9.0→v0.10.0 与 SKILL v1.12.0→v1.13.0 同步改写规则 C/D、新增规则 H、协议产物与约束主体两节、补写隔离边界声明，并承接 0019 的 D-1 偏差。

## 涉及功能点

- F01（零前置会话启动：任意位置启动 + 工作区由会话自建，不等候不请示）
- F02（显式寻址纪律：文件写入用绝对路径、git 写操作用 `git -C <地址>`、零工具依赖）
- F03（协议产物存在与落点：规范侧声明 `docs/worktrees/README.md` 的落点与被跟踪——真源面）
- F04（产物内容骨架：规范侧给出「必须覆盖 5 类信息」的模板与「非第二真源」分工）
- F05（落点语义澄清：规范侧持有区分句真源，产物侧只作一行承接）
- F06（工作区地址确定性解析：解析链不读 `pwd`、可被简报字段显式覆盖）
- F07（地址声明三层分层：投影 1 = `status.md` 字段、投影 2 = 简报字段；源在 pr-002）
- F08（简报两级寻址纪律 + `## 文档路径协议` 基准句改写）
- F09（硬停面收窄为「工作区无法确定或无法创建」一处 + 删除 cwd 启动门 + 输出不含祈使句）
- F10（主工作区定位重述：可作启动位置、不得作工作区、写入仍受规则 F 约束）
- F11（supersede 逐句显式声明：被取代清单 + 保留清单，落在 v0.10.0 变更说明）
- F12（已知代价显式化：cwd 不在隔离范围、越界不可被 git 强制、只能事后核查）
- F13（机制骨架不变：worktree 唯一形态 / 每迭代一个 / 迭代分支 / PR 子层 / 并发算法 / 七字段）
- F14（阶段 5 子 agent 以简报给定的 PR worktree 绝对地址为准；旧「被派发时所在的工作区」口径删除）
- F15（0019 E 项承接三分类：保留 E1~E4/E6/E7/E9~E13、改写 E5/E8、新增两条）
- F16（0018 活指令失效登记 + 恢复派发覆盖句；0018 文件零改动）
- F17（D-1 承接：`### 隔离边界声明` 补章节级 `判断方式：` 行）
- F19（约束主体显式分离：「对人」零前置段与「对会话」三项纪律段分写）
- F20（做事时检测：简报带 `检测项` 一行 + 执行者自检；不设启动前准入门）
- F21（规范形态约束：零 hook / 守卫 / 工具依赖；本轮新增或改写的每条条款自带 `判断方式：`）
