### D-04 一次性路径的注入必然改变 `omp -p` 的末位 argv

| 项 | 内容 |
|---|---|
| **待确认** | 一次性路径携带项目上下文只能落在 prompt 上（`omp` 无"内联系统提示"参数；`--append-system-prompt` 收的是**文件路径**），因此该路径派发时的末位 argv 会从 `<原文>` 变成 `<【项目上下文】块>\n\n<原文>`，既有 argv 断言与"桩回显"断言随之改写 |
| **推荐** | **接受**（F06 验收 2 要求一次性路径也携带；argv 是载荷装配的直接投影） |
| **备选** | 无可行备选：改走临时文件 + `--append-system-prompt` 会引入"文件写入 / 清理 / 并发"一整套新机制（违反奥卡姆与零新机制口径） |
| **影响面** | 既有测试 8 处观测断言的改写（`architecture.md` §8.2② 的 (d) 类）；派发载荷的对外可观测形态 |
