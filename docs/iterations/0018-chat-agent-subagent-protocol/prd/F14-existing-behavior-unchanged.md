## 验收标准

1. **既有已文档化契约逐条保持**（N18 / E9）：既有消息入口的响应形态、既有实时订阅的事件语义与顺序、统一错误契约（`{error, code}` 封闭枚举）、「已知路径用错动词走找不到兜底（**不引入 405**）」、对话的归档 / 关闭 / 激活 / 改名状态机——逐条与改动前一致。
   *判定*：按既有用例覆盖的形态逐条实测，结果与改动前一致。
2. **既有测试面零改写通过**（N18）：既有测试中与调用面无关的部分**文本零改写**且全绿；必然变更处需逐条给出理由并落在显式清单内。
   *判定*：对既有测试文件做版本对比（除清单列出的必然变更点外 diff 为空）+ 运行全部既有用例。
3. **变更面闭合、无越界变更**（N18）：与调用面**必然变更**的点被显式记录、互不遗漏；除这些点外无其它既有行为变更。
   *判定*：全量用例 + 逐条比对，变更点全部落在记录清单内。
4. **协议面零变化**（N15 / E9）：agent ↔ router 的方法面数量与名称无增无删。
   *判定*：对照既有协议速览与方法注册处逐条比对。
5. **上下文语义不变**（N16，与 F12 验收 3 同源）：上下文键、同键串行 / 异键并发、上限与淘汰策略逐条不变。
   *判定*：对照既有上下文行为逐条核对。
6. **既有安全边界不变**（N19）：仍为本机监听、无鉴权；不新增对外暴露、不新增鉴权。
   *判定*：检查监听范围与鉴权面，与改动前一致。
