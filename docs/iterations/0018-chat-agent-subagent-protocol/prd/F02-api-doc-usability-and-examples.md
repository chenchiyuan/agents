## 用户价值

客户端作者不用读源码，照文档里的发起示例与订阅示例各粘一次就能接上——「读了接口文档之后可以接入使用」是交付形态本身（承 0015 N11）。

## 验收标准

1. **三面各自有接口说明**（W7）：文档按调用面 / 响应面 / 展示面分别给出接口说明——每条的用途、请求要带什么、返回什么、失败是什么样，以及各条与「一次调用」的关系。
   *判定*：文档中三面各成一节；逐条能读出输入与返回；不存在「只有路由表、没有用法」的路径。
2. **可粘贴示例齐备**（W7）：文档给出可直接复制的示例——发起一次调用、按调用 id 取终态、按调用订阅（订阅类的流式示例），示例中的地址与参数形态与本机默认监听一致。
   *判定*：把示例粘到终端执行 → 不因「示例本身写错」而失败（角色在线的正常路径下能发起、能取回终态、订阅能收到事件）。
3. **示例与实现一致**（W7 / E2~E7）：示例中出现的请求要素与返回字段，与实现的实际形态一致——不存在「示例里有、实现里没有」或反过来的情况。
   *判定*：照示例逐项对照实现返回；不一致项为零。
4. **接入不需要本仓库提供代码**（N1）：文档不承诺任何客户端 SDK / 插件 / 适配器；接入形态 = 「读文档 + 客户端自行实现调用」。
   *判定*：文档与仓库中均无客户端接入代码 / 插件（协同 F15 验收 1 的零半成品检索）。

## 边界（不包含）

- 不含对照表与差异清单的**完整性**（→ F01）；本卡只断言「接口说明与示例可用、与实现一致」。
- 不含路由 / 事件登记与工程锁（→ F16）。
- **不实现客户端 SDK / 插件 / 适配器**（N1）：不为 omp / codex / claude 写接入代码。
- **不做 `oamp/` 之外的仓库改动**（N20）。
- 不含部署、鉴权、外网暴露相关内容（本机监听、无鉴权为既有边界，N19）。
- 不定义示例之外的字段语义（字段内容归 F04 / F06，本卡只保证示例与实现一致）。
