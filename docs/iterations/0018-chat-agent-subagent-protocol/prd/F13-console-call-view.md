## 用户价值

不开终端也能看见调用——在控制台里一眼看到正在跑什么、跑完没有，不用切到命令行去 curl。

## 验收标准

1. **存在可进入的「调用」面**（W5）：控制台中有与既有对话面并列的调用面，可被进入。
   *判定*：打开控制台 → 能找到并进入该面。
2. **面内可见 roster**〔`[user_confirmed MI-03 / MI-07]`〕（W5 / E7）：该面按行呈现调用（调用 id / agent / 状态 / 起止时间 / 模型），口径与数据面一致（批量两项 ⇒ 两行；起止时间取受理 / 终态时间、进行中为空；roster 为展示面，无过滤与编排入口）。
   *判定*：发两次调用后打开该面 → 看到两行且信息齐备。
3. **面内可见进行中的进度**（W5 / E6）：某调用进行中时，该面能反映其状态与增量（不要求工具级细节）。
   *判定*：发起一次较长调用并停留在该面 → 状态与增量随调用推进而更新。
4. **不呈现无数据源的字段**（N12 / 差异 ⑬⑭）：该面不显示 token、成本，也不显示工具级详情。
   *判定*：逐列核对 → 上述字段零出现。
5. **既有控制台面行为不变**（N18）：既有对话面与其行为逐条不变（新面为新增，不重写既有面）。
   *判定*：对照既有控制台行为逐条核对（协同 F14 验收 1）。

## 边界（不包含）

- 不含数据面的定义（→ F05 / F06 / F08 / F09）；本卡只断言「这些数据在控制台可见且口径一致」。
- **不做远端同会话渲染一致**（N13，差异 ⑰）。
- **不含取消 / 终止 / steer 的界面入口**（N3，差异 ⑯⑮）。
- 不含鉴权与多用户视图（N19）。
- 不含视觉风格改造与既有面重排。
- 页面划分与呈现形态留架构（T-07）。
