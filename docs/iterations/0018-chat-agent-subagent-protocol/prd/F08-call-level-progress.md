# F08：调用级进度可见

**功能 ID**: F08
**来源**: `demand.md` W5（进度侧）+ W3（订阅进度能力）；裁决 P-7（按推荐：D1 部分等价）；边界 N11 / N12；差异 ⑬；效果 E6
**迭代**: 0018-chat-agent-subagent-protocol
**技术锚点（引用 `demand.md` §3 只读实测，非本阶段决策）**: F-12（增量输出形态为逐行或分块，行数封顶）、F-6（任务表维护状态迁移与增量集合，上限后置截断标记）、F-11（既有实时流只有 chat 作用域与全局上线事件流）

---

## 用户价值

等着的时候能看见它在动——状态走到哪一步、吐出了什么，不用靠猜「它是不是卡住了」。

## 验收标准

1. **状态迁移可见**（W5 / D1 / E6）：调用期间，订阅方能观察到该调用的状态变化（至少覆盖：开始受理 → 进行中 → 存在终态）。
   *判定*：观察一次调用的完整事件序列 → 状态迁移逐段出现且顺序正确。
2. **增量输出可见**（W5 / D1 / E6）：调用期间能看到该调用产出的**增量内容**，不是只在最后一次性出现。
   *判定*：发起一次持续输出的调用 → 过程中连续可见增量（≥2 次增量事件）。
3. **序列闭合于终态**（E6）：观察到的序列以该调用的终态收尾（终态事件本身 → F07）。
   *判定*：一次完整订阅观察 → 事件序列闭合于终态，无悬空、无「有头无尾」。
4. **增量与转录一致**（W4，与 F10 配套）：过程中看到的增量内容，与随后按调用 id 取到的转录一致——不出现「流里有、转录里没有」。
   *判定*：同一次调用，对照流中增量与转录内容 → 一致。
5. **不做工具级详情**（N12，差异 ⑬）：进度面不呈现「当前工具 / 参数 / 意图 / 重试」级别的细节，也不呈现 token 与成本。
   *判定*：检索事件内容与文档 → 上述字段零出现。

## 边界（不包含）

- 不含终态投递保证（→ F07）、不含终态字段内容（→ F06）、不含转录读取入口（→ F10）。
- **不做工具级实时进度与 token / 成本**（N12，差异 ⑬⑭）。
- 不含控制台呈现（→ F13）；本卡只断言数据面可观察。
- **不承诺跨重启重放**（N11，差异 ⑩）：进程重启后无历史进度可重放。
- 不含取消 / steer 的交互入口（N3，差异 ⑯⑮）。
