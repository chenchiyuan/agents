## 用户价值

一轮对话还没结束，我就能在对话里看见它正在想什么、正在调什么工具——而且这些过程不会污染历史记录。

## 验收标准

1. **轮次结束前可见（界面面判据）**（E3 / J3 / U-4）：**默认 rpc 链路**下一轮执行**期间**（轮次结束前），**打开控制台的对话详情**可见**思考增量**与**工具参数 / 输出增量**。
   *判定*：**打开控制台对话详情**核对这些内容是否在轮次结束前**实时**出现、**确实在界面上出现**。 〔`[user_confirmed MI-01]`：本卡判据面 = **界面面**；"管道有没有把三类东西带上"由 F04 在管道面判，两卡判据**不重叠**——界面上看不到时，能区分是**管道丢了**（F04）还是**管道有、界面没接**（本卡）〕 **acp 链路不在本项范围**（N12 / A4）。
2. **落在既有对话详情内，不新增 UI 载体**（M3 / A3/P4）：过程增量走**既有的按对话运行时通道**（等价 `task_update` 语义），落在**既有对话详情**内；**不新增 UI 载体**（不新开面板、不新增页面）。
   *判定*：看过程出现的位置 → 在既有对话详情内；控制台无新增面板 / 页面。
3. **不入库，不改记录条数边界**（E3 / J3 / N4）：同一轮结束后，存储中**仍只有 in / out 两条记录**（过程不入库）；不改「一次问答恰两条记录」边界。
   *判定*：轮次结束后查记录条数 → 恰两条（过程增量不产生额外记录）。
4. **不做开关 / 过滤 / 分级**（N5 / A3/P4）：不新增过程展示的开关、不做过滤策略、不做分级偏好。
   *判定*：查控制台与配置面 → 无过程展示的开关 / 过滤 / 分级项。

## 边界（不包含）

- **不含过程增量的持久化 / 回放 / 检索**（N4）；不改「一次问答恰两条记录」。
- **不含过程展示的开关 / 过滤 / 分级偏好**（N5）。
- **不含 acp 链路的思考 / 工具输出增量**（N12 / A4）。
- 不含过程增量的**透出粒度**（原样 vs 聚合）与**呈现形态**（视觉区分 / 折叠等）（→ T-06）。
- 不含过程增量在运行时通道上的承载形态（帧 / 事件形状与既有通道的衔接方式）（→ T-07）。
- 不含**节流策略**（R5：已知代价，本迭代不做，若体感不佳属下一迭代输入）。
