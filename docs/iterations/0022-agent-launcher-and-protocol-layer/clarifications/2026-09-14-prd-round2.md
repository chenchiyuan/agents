## 0. 本轮性质与硬性限制

- 本 agent 运行在**无实时对话通道**的子 agent 中，**无法直接与用户对话**；本轮**只做裁决回收与收敛自检**，**不产生新问点**（若出现新缺口才标 `[model_inferred]` 转呈——本轮未出现，见 §6）。
- 用户裁决是 `user_confirmed`：**不重问、不推翻、不把被改写的旧措辞当结论**；旧措辞（首轮推导值）在 `prd.md`「MI 判定口径」表中**并列留档**，不作生效口径。
- **不新增功能点、不新增条款**：MI-02 的三条生效口径**全部落在已落盘需求 W1 / W2 / M6 范围内**（证明见 §3）。
