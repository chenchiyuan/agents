## 验收标准

1. **agent 侧的协议方法与能力面零改动**（N3）：本迭代**不新增、不修改** omp / harness 侧的协议方法、帧类型与工具清单。
   *判定*：对照改动前后的上游面（协议方法清单 / 帧类型清单 / 工具清单）→ **一致**。
2. **所需能力均为上游既有**（N3 / K3 / K7 / K12）：提问承载（`rpc` 宿主工具面、`acp` 原生 `ask` → `elicitation/create`）、档位取值（`always-ask` / `yolo`）、门机制均为**既有**能力，无需上游改动。
   *判定*：逐项在既有上游面上可核（`rpc` 宿主工具通路 K12 实测可跑、`acp` 提问面 K3 已存在、档位 flag K7 已在）。
3. **"必须改上游"时停下来报告**（N3 的边界纪律）：若某条验收标准被证明只有改上游才能满足，**不自行改上游**——停止并上报。
   *判定*：复核改动面 → 上游零改动；若存在上游改动，检查是否附"停止上报"记录（无记录即违反）。
