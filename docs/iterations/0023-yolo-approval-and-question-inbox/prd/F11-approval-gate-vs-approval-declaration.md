## 用户价值

"这个协议有没有这道门"和"这次开不开这道门"是两件事——不会因为档位一改，能力说明就跟着变。

## 验收标准

1. **能力位不随档位变**（M8 / A4-P10）：描述"该协议**是否有工具门这一机制**"的能力位取值，**不随档位（`always-ask` / `yolo`）变化**。
   *判定*：以两个档位分别起同一协议的会话 → 对照该能力位取值 → **相同**。
2. **档位由档位声明单独表达**（M8 / A4-P10）："**本次生效形态**"由 profile 的**档位声明**（`approval` 字段）单独表达。
   *判定*：读该协议的 profile 档位声明 → 与本次实际档位一致；档位变化时只有该声明变、能力位不变。
3. **两件事不混写**（M8 的理由面 / 0022 `D-1` 体例）：能力位语义 = "**协议是否有该机制**"，**不含**"本次是否生效"。
   *判定*：读能力位定义 → 只有机制有无，无档位取值；不存在"档位 = `yolo` ⇒ 该协议不生效"的表述。
