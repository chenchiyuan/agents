## 用户价值

没人管的时候它就等着——系统不会背着我替它选一个，也不会替我把它拒了让整轮突然断掉。

## 验收标准

1. **默认阻塞、无上限**（M6 / A4-P13 / E5）：提问类请求登记后该轮**保持等待**；放置**任意长时间**后条目仍在栏内、轮次仍处于等待。
   *判定*：**放着不管一段时间后再看：条目仍在、轮次未推进**。 〔判定方式逐字取自 E5 的裸判据〕
2. **无超时退化、不自动选推荐项**（M6 / A3-P7 / A4-P13 / **N2**）：不超时收尾、不自动选"推荐项"（`recommended` 仅作展示）；`ask.timeout` 保持默认 `0`。
   *判定*：放置任意长时间 → 无自动作答发生、该轮未收尾；控制台中不存在"提问自动裁决"策略面。
3. **不代答拒绝**（**N12** / A3-P7 / E5）：不以 `decline` / `{cancelled:true}` 兜底；该轮**不因提问未被回答而以 cancelled 收尾**。
   *判定*：搁置后再看 → 该轮状态仍为**等待**（**未 cancelled**）；提问侧未收到任何拒绝 / 取消应答。
4. **不做自动裁决策略配置面**（**N2**）：控制台中不存在"默认选项 / 自动放行 / 自动拒绝"的提问策略面。
   *判定*：找遍控制台 → 无相应配置面（**沿用 0021 `N6` 的既有裁决**）。
5. **挂起语义与既有面一致**（M6，0021 体例）：提问类的等待态与既有工具门等待态在用户可见面上一致（同一栏、同一"等待中"状态）。
   *判定*：对照一次工具门挂起与一次提问挂起 → 栏内状态语义一致。

## 边界（不包含）

- 不含**作答之后**的行为（→ F07）；不含提问形状与条目数（→ F05 / F06）。
- 不含 `kind:'permission'` 类的挂起（0021 `F05` 既有：默认阻塞无上限；本迭代不改 → F10）。
- **不含无人看守代价的处置**（R3 已是**已登记代价**，本卡不派生任何缓解功能点——"自动作答 / 代答拒绝 / 超时收尾"三种缓解均被 N2 / N12 封死）。
- 不含"无上限"的**机制归属**（提问通路上计时 / 超时由谁保证 → T-08；行为已钉，机制留白）。
- 不含覆盖面之外路径（一次性 `omp -p` / `!` shell → **N5**）。
