## 用户价值

这次不把服务开到局域网或公网去——本机和以前一样。

## 验收标准

1. **服务边界不变**（N8）：服务仍**仅本机监听**、**零鉴权**、**不做多用户 / 跨机**。
   *判定*：复核监听地址与鉴权面 → 与 0021 既有结论一致（仅本机、无鉴权、无多用户）。
2. **新增通路不放宽边界**（N8 的适用面）：本迭代新增的提问通路与档位配置面**不引入对外可达面**（不新增监听地址 / 端口 / 对外开放接口）。
   *判定*：枚举监听地址与端口 → 仍为本机既有端口；提问通路不新增对外入口。
3. **不因"提问需要人回答"而把服务外放**（N8 / U-3 的边界面）：提问上浮仍是**本机控制台内**的事，不做远程 / 跨机器送达。
   *判定*：复核提问条目的可达面 → 仅本机控制台。

## 边界（不包含）

- 不含既有接口面的细节（0021 既有交付物；本迭代不改）。
- 不含通知的其它入口载体（**N7** 封死 → F04 边界）。
- 不含鉴权 / 多用户 / 跨机能力的预留（不做，且不预留扩展点）。
