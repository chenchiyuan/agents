## 用户价值

这个栏只装"还要等我处理的事"——处理完就干净，不会堆成另一个消息中心。

## 验收标准

1. **不提供已裁决条目的历史 / 检索面**（N9）：控制台中**不存在**"我看过 / 处理过哪些确认（含提问）"的历史入口或列表；已裁决条目**不在栏内留存**。
   *判定*：找遍控制台 → 无已裁决条目的查看面；栏内只有未裁决项。 〔判定面 = **用户可见面**（0021 MI-03 的既有口径）；**不判数据层**〕
2. **范围澄清：不覆盖未裁决的在途项**（N9 / 0021 `N2` 的 T-3 澄清）：未作答的提问条目**必须仍在栏内**（含刷新 / 断线重连后）。
   *判定*：未作答条目刷新页面后再看 → **仍在**（本边界不得削弱在途可见性）。
3. **提问类同样不做台账**（N9 的适用面）：已作答的提问条目不产生作答记录台账。
   *判定*：复核 → 无已作答提问的历史面 / 无问答记录列表。
