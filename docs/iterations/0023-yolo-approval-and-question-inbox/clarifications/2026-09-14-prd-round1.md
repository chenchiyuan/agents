## 二、粒度判断（非一对一的六处，供主 agent 复核）

1. **W1 → F01 + F02**："默认下零门"与"档位可配"可独立失败（写死 `yolo` 满足 E1 却违反 E8；默认值错则反之）。
2. **W2 → F03 独立成卡**（与 W6 的 F10 分界）：两者是**不同实例**的不同结局——`deny` 实例"门存在但不给人"（自动拒绝、不进收件箱）；`always-ask` 实例"门存在且给人"（上浮、由人裁决）。
3. **W3 → F04 / F05 / F06 / F08**：四个判据面互不重叠（条目是否出现 / 条目能表达什么 / 条目数 = N / 搁置后的状态）。F04 与 F08 的切分**沿用 0021 `F02`（源上浮）与 `F05`（挂起语义）的先例**。
4. **W4 / W5 → F07 / F09**：W5 的失败模式是"默认链路上根本没有提问承载"（起点材料 R1 的原始缺口）；W4 的失败模式是"承载有了但答案丢了"（K4 的载荷缺口）。两者可独立失败 → 拆两张。
5. **M8 → F11（一张，〔形态约束〕）**：能力位与档位声明的分离横跨 F01~F03 与 F10；拆进各卡会让同一机制失去单一承载点（体例先例：0022 `F09`）。
6. **M2 / M7 未另立卡**：M2 的两档语义分别由 F01（`yolo` 面，验收 2）与 F10（`always-ask` 面，验收 1）承载；M7 的两条通路承载由 W5 的卡（F09）承载——**未新增卡**。

**原子粒度自检**：每张卡可被**独立测试 + 独立交付**；每张卡的每条验收都能回答"QA 怎么测"（逐条带 `*判定*`）。

## 三、MI 判定口径（**3 项 · `[model_inferred]` · 未生效 · 待转呈**）

`demand.md` 的 `model_inferred` 已归零、转呈件清单为空。以下 3 项**不是需求结论**——是拆卡时遇到的"**验收标准的判定口径存在多解**"：两个（或三个）读法都能满足 `demand.md` 的明文，但验收判定面不同。**本 agent 无实时对话通道，严格执行零自问自答**：卡内以 `[model_inferred MI-xx]` 标记**未生效**的首轮推导值，并列出备选读法，**不替用户裁定、不自我宣布生效**。

### MI-01 · 非法档位取值的处置 · 落点 = F02 验收 4

- **缺口**：E8 只写"配置面只接受两个取值（…其余被拒）"，**未定义"被拒"的用户可见后果**。
- **首轮推导值（未生效）**：非法取值 ⇒ **拒绝启动并报错**（不静默回落）。
- **备选读法**：① 拒绝启动并报错；② 忽略非法值、按默认 `yolo` 启动（给告警）；③ 启动但档位保持内置默认、不提示。
- **不问清会怎样**：三种读法都满足"仅两值合法"，但判定面完全不同（看报错 / 看起不起得来 / 看行为落到哪一档）⇒ 阶段 6 的裸判定会出现分歧。

### MI-02 · `deny` 档的拒绝观测链路 / 观测面 · 落点 = F03 验收 3

- **缺口**：E2 的第三半句要求"agent 侧有拒绝痕迹（`TOOL_DENIED`）"，而 K6 明确 **`rpc` 链路全文件零审批审计行**；本迭代的**默认链路正是 `rpc`** ⇒ 该半句在默认链路上不可观测。
- **首轮推导值（未生效）**：`deny` 档的拒绝观测面 = **`acp` 链路**（该链路上 `TOOL_DENIED` 可观测）；默认 `rpc` 链路另以"**收件箱零新增条目 + 该轮中止**"为观测面。
- **备选读法**：① 上述双面读法；② 要求 `rpc` 链路也产生等价拒绝痕迹（**与 N4「不新增审计面」相撞**）；③ 本项只在 `acp` 链路验收。
- **不问清会怎样**：本卡在默认链路上无法判定（E2 与 K6 不相容）；读法②会连带推翻 N4 的裁决。

### MI-03 · 提问类作答的必填性 · 落点 = F05 验收 5（+ F07 验收 1）

- **缺口**：A3-P4 只裁"支持无选项的纯自由文本提问"、A3-P6 只裁"回答**必须回传自由文本**"，**未裁"带选项的提问能否只用文本作答"**；0021 `F03` 把"文本是否必填"列为架构待填（T-04），但那是 `permission` 类。
- **首轮推导值（未生效）**：**至少填其一**（选项与自由文本二者至少一个非空即可提交；纯自由文本提问下文本必填）。
- **备选读法**：① 至少填其一；② 带选项的提问**必须**选一个选项（文本仅附加）；③ 两者皆可空（空提交 = 不作答语义）。
- **不问清会怎样**：F05 验收 5 / F07 验收 1 的判定面（可提交 / 必须选 / 空提交如何处理）无法冻结。
