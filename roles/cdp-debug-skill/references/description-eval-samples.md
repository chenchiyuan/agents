# description 触发样例集（离线 eval 复用）

供评审离线执行 F03 §4 裸判定 2：把 SKILL.md frontmatter `description` 与本样例集交给触发评估 → 逐条判定命中/不命中。

**判定口径**：`should-trigger` 样例应命中 description 正向面（做什么段/何时用段）；`should-not-trigger` 样例应落入 description 否定边界（不适用段）而不命中。

**自宣边界（D10/F03）**：样例仅供评审者复用；description 命中率判定由评审离线执行，**不随本交付物声明已通过**——本 skill 交付物不含触发 eval 运行基建。样例与文件措辞不引用 powerby 跨仓技能、不声明 pb 生态横向能力（pb-v1-brower 式任务仅作 should-not-trigger 边界对象点名）。

## should-trigger（≥5）

1. **主链路·自动操作断言**："帮我打开 http://localhost:5173 的注册页，填表提交，断言出现欢迎提示并截图"
   依据：命中"何时用——自动操作与断言"+ "做什么——对真实页面做自动操作与断言（@playwright/mcp）"。
2. **主链路·页面调试**："https://staging.example.com 上把商品加购后，断言购物车角标变成 1"
   依据：同上（真实页面调试 + 断言）。
3. **诊断·失败排查**："结算页提交一直报 500，帮我抓 console 报错和失败的网络请求，定位页面原因"
   依据：命中"何时用——页面失败与断言不通过排查"+ "做什么——失败深诊（console/网络取证）"。
4. **诊断·性能深诊**："这个页面加载很慢，帮我做性能 trace，看卡在哪一步"
   依据：命中"做什么——失败深诊（性能证据，chrome-devtools-mcp 诊断链路）"。
5. **登录态续调**："新开会话不用重新登录，直接帮我验证个人中心页还能不能正常进"
   依据：命中"何时用——需保留登录态跨会话续调的页面任务"+ "做什么——登录态续调（CDP 独立 Chromium + profile）"。
6. **组合语境**："登录后跑一遍下单流程断言；如果断言失败，对失败页面做深诊"
   依据：命中"何时用——'登录后跑操作断言''操作失败后深诊'这类组合任务"，组合编排（登录态先就绪 → 主链路 → 失败转诊断）。

## should-not-trigger（≥5）

1. **N2·测试框架编写/CI**："帮我写一个 playwright 测试文件，并接到 CI 里每次提交跑"
   依据：落入否定边界"纯测试框架编写与 CI"——不命中。
2. **N2·压测/性能基准**："对结算接口做 1000 并发压测，给出吞吐和延迟基准报告"
   依据：落入否定边界"压测/性能基准"（宿主 benchmark 职责）——不命中。
3. **N2·视觉回归基线**："给商城页面建立视觉回归基线，每次部署后对比截图差异"
   依据：落入否定边界"视觉回归基线"——不命中。
4. **N1·评审/验证协议任务**："对这次改动的页面做 review/verify 评审，输出 findings 清单和结论"
   依据：落入否定边界"pb-v1-brower 式评审/验证协议任务"——不命中。
5. **普通网页浏览取数**："打开 example.com 把首页标题和正文抓给我"
   依据：落入否定边界"普通网页浏览取数（web-access/browse 语境）"——不命中。
6. **investigate 语境·系统级调试**："后端服务一直 502，帮我从服务端日志做根因分析"
   依据：系统级根因调试（investigate 四阶段语境），非"页面失败排查/页面级证据采集"——不命中。
7. **批量浏览取数**："批量抓取 500 个商品页的标题和价格入库"
   依据：落入否定边界"普通网页浏览取数"（批量抓取同样非调试闭环任务）——不命中。
